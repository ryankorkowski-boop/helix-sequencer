# Showcase 12

Twelve synthetic xLights layouts, ordered from a 16-channel LOR house to a snowman band on a stage. They are generated by `tools/showcase12/generate_layouts.py`. No private layouts, songs, or tester files are included.

| Panel | Title | What it is for |
|---|---|---|
| s01_ac16 | LOR 16 House | House outline, four mini trees, wreath, door, arches |
| s02_ac64 | LOR 64 Yard | Same LOR vocabulary, 64 channels |
| s03_ac256 | LOR 256 Show | Big AC yard, 256 channels |
| s04_rgb_porch | Pixel Porch | First RGB yard: roofline, windows, mini trees |
| s05_arches_faces | Arches And A Face | Arches, spinners, one singing face |
| s06_pixel_yard | Pixel Yard | More arches and spinners, two faces, a singing-tree face |
| s07_mega_yard | Mega Tree Yard | 360° mega tree with a star, strip matrix, singing face |
| s08_busy_rgb | Busy Pixel Show | Dense arches, four spinners, singing faces and singing-tree faces |
| s09_mega_grove | Mega Grove | Two 360° mega trees with stars, spiral tree, singing-tree faces |
| s10_helix_tunnel | Helix Tunnel | Double helix, spirals, concentric rings, dense spinners |
| s11_matrix_wall | Matrix Wall | 40×20 panel matrix, strip matrices, three singing faces |
| s12_band_stage | Snowman Band Stage | Snowman band, stage, backdrop matrix, drums, singing faces, mega tree |

Singing faces use an xLights `faceInfo` NodeRange definition (AI, E, FV, L, MBP, O, U, WQ, etc, rest, plus eyes). Run the master profile with `--sync-lyrics-heads` so those models receive a Faces effect driven by the Phonemes timing track.
