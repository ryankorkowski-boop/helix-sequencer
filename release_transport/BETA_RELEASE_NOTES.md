# Helix Beta Release v1.0

Windows and Android were built and tested from b7576e28008b938b0f4d832ae3f2688bde996444, the GitHub PR merge snapshot with exactly the same tree as integration commit cb6cff6bcf0227386a244b4bf2ea369ee9bab228. The default branch has not been merged.

Windows run 38517654958 passes packaged GUI startup, real xLights/LOR engine execution and native FSEQ preview. Android run 38517654938 passes API 30/API 36 tests covering MP3/WAV, complete 237.44-second sequencing, preview playback, export recovery, cancellation and same-key reinstall within each run. Full-song sequencing smoke uses a three-second preview; a complete 237-second Android preview is not certified. The APK is debug-signed. Windows includes its dependencies; unsigned Android production packages are excluded.

The full local suite passes 1,470 tests, with five skipped because the fixed 2.wav fixture is unavailable. Strict Python 3.11/3.12 CI supplies FFmpeg, zstandard, moderngl and pronunciation data and no longer hides audit failures. Typed-drum metadata, actual V3 stem-map identities and validated legacy-flat vocal XSQ support are repaired. Detector thresholds, original audio/layouts and approved guitar motion are preserved.

The accompanying diagnostic package contains an 18-house, 1,081-model 3D layout at 9.082 times baseline XZ area, 88 addressable keyboard rungs and a twelve-channel fixed-lighting diagnostic. Synthetic eight-kick proof checks timing/wiring; it does not certify the reported real-song passage. Tom contacting-stick poses need additional strings/pixels. Complete animated stages and full musical choreography are not claimed.

Eleven distinct recordings exist across the repository and archived inputs. None has complete creation-account/date matching redistribution evidence. All song audio/movies are omitted. Full LightsOutTheme.mp3 is unavailable.

Remaining: one unified magic-key/mallet performer, the complete second band, independently verified dual vocals, original rapid-kick coverage, six-layout/full-song movies and the full-song showcase ZIP. Actual Samsung/ARM64 use, previous-signing upgrades, controllers and native vendor LOR import remain unverified.
