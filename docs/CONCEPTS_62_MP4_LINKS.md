# Approved concepts 1–62: files and MP4 links

All 62 approved concepts now have native xLights shows and 24-second MP4 previews.

The first 22 shows retain their original XML/XSQ files byte for byte; their movies have been regenerated. Designs 23–62 were converted in this delivery.

Includes reusable XMODEL files, XML layouts, XSQ sequences, rendered FSEQ files, all 62 individual MP4s and download packs. The movies are silent and use actual xLights-rendered lighting projected onto the exported geometry.

Validation: 62 native renders, all 2,714 models lit, all 62 movies fully decoded, 127 focused tests passed, and six portable show checks produced identical native frames.

Downloads are hosted on the dedicated artifact branch in this repository.
