# Helix Android 0.3.0 stability beta — release text

Candidate notes for the project's authorized GitHub release workflow. This file
does not itself publish a release.

Changes: guided Music → Layout → Style → Advanced → Generate → Results flow,
first-run help and saved settings; expert-only Birdsong/Matrix Intelligence/Polish;
optional Neon and automatic RGB chorus/drop chase; robust MP4 extended/EOF box
parsing and measured soundtrack edits; independent sequence/ZIP/preview results
and direct sequence export even after a preview failure; scoped ZIP sharing.
Both existing donation links and desktop pairing remain available.

Install only the APK from the [official Releases page](https://github.com/ryankorkowski-boop/helix-sequencer/releases).
Read the [beginner installation guide](ANDROID_INSTALLATION.md), including
temporary Samsung Auto Blocker handling and signing/update troubleshooting.
Re-enable security settings after installation.

Debug beta APKs are signed for testing. An unsigned release APK/AAB cannot be used
as a production update. Save shows before removing an older beta signed with a
different key. Current offline dependencies require Android 8+, a supported
64-bit ABI and 4 KB pages. MP4 previews are simulated model-level effects with the
actual soundtrack; native xLights/LOR/controller playback needs separate testing.
LOR supports legacy LMS addresses; native loredit/LCC are not supported.

Attach APK/AAB checksums, actual signing certificate, exact source commit,
device/codec evidence and known limitations when a release is authorized.
Play preparation status: [readiness assessment](GOOGLE_PLAY_READINESS.md).
