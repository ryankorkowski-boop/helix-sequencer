Your first Helix show

Helix instructions — Beta 1.4 preparation (check installed app version)

1. Choose your music (MP3 or WAV is a good starting point).
2. Choose xLights or Light-O-Rama.
3. For xLights, import xlights_rgbeffects.xml and optionally your XSQ template/controllers. For LOR, import an existing LMS containing your real Unit/Circuit addresses.
4. Choose an output folder on desktop. On Android, generated shows stay private until you save or share them.
5. Keep the default colors and automatic musical response to start. Advanced controls are optional. Neon is only an optional RGB palette.
6. Generate. Full song is the default. Quick clip sequences only the first ten seconds when enabled; preview length is otherwise separate.
7. Request 1–8 variants. In Results, select an individual sequence and use Play preview or Save MP4 when its video is available. A pending or failed video does not invalidate a completed sequence. Save the sequence and complete show ZIP. Keep the soundtrack, layout and controller files together.
8. Import and check the show in your lighting software before controller playback.

Band performers: in Layout, turn Band performers on to include the performers already present in your selected xLights layout. Turn it off for a lights-only sequence and preview. The choice is remembered. Helixville 4 includes a band; the switch does not add performers to a layout that has none. LOR retains your addressed channels.

Instructions and Legal each remember their scroll position while you switch pages or rotate the phone. Quick clip sequences the first ten seconds when enabled.

Helix Review installs alongside Helix, leaving the working app and its private shows in place. Select the music/layout again in Review, or export files from the existing app. It does not automatically transfer private settings or jobs between the two apps.

If the preview fails, your completed sequence can still be saved. Read the run report for the specific error. Native .loredit/LCC import is not currently supported.

Android installation: use the project APK and verify its published checksum. Open it in My Files/Files, allow that trusted app to install it when prompted, and temporarily disable Samsung Auto Blocker if it blocks the install. Recheck its state if necessary and re-enable protection afterward. Keep the old app and back up shows before an update; a different signing certificate cannot update the old installation.

Desktop control from your phone is optional and requires reaching your own Helix desktop server. Local Android sequencing does not require a desktop.

Preview and export notes

Android previews are simulated Helix model previews, not native xLights renders or proof of FSEQ compatibility. Open the exported XSQ with its matching layout and audio in xLights, render there and inspect channel mapping before connecting controllers. AC/LOR mode preserves addressed channels; RGB-only effects are not intended for AC circuits.

For memory-constrained phones, start with one variant and a short preview. Quick clip reduces the sequence to ten seconds; shorter preview duration alone does not shorten full-song analysis. If Android interrupts processing, check Results and the run report for any completed exports. Eight-variant device acceptance and expanded preset verification remain in progress for 1.4.

Beta 1.4 benchmark layout guide (availability depends on build)

The nine target presets are 16-channel LOR AC, original 256-channel AC, RGB house, house with coro singing faces, canonical six-snowman band, singing trees and matrices, 3D spatial grid, keyboard-driven sequential groups, and extreme Helix showcase. Preset availability and native compatibility are still being verified. Do not substitute a generated channel map for Greg's original AC map or the owner's 16-strip tree.

Advanced controls and vocal sources

Start with defaults and change one engine setting at a time where exposed. Compare variants using the same audio and layout. Independent singer and phoneme support is under acceptance testing; estimated separation is experimental and is not equivalent to verified independent stems. A recording without backing vocals should not produce a fabricated harmony performance.

Desktop installation and recovery

Use the project-provided Windows package and published checksum when available. Extract portable packages into a writable folder before launching; preserve your existing layouts, audio, controller mappings and exported shows before updating. If processing is interrupted, retain completed sequences and inspect the run report before retrying. Windows 11 package acceptance remains pending. Do not assume interrupted jobs can resume automatically.

Native export and safety

Keep XSQ, layout, audio and controller configuration together. Render FSEQ using compatible native xLights and check timing, channel counts and controller mapping before output to physical lights. Review LMS exports in Light-O-Rama. A playable MP4 is a visual preview, not a controller-ready sequence. Consult the bundled Legal and licensing information; donations are optional. Consult the release manifest for verified platforms, manual versions and package checksums.
