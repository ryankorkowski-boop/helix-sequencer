# Approved concepts 1–62: xLights files and MP4 previews

All 62 approved designs are converted. Original 1–22 XML/XSQ files are unchanged; designs 23–62 are newly built.

Each MP4 is a 24-second silent study from actual xLights-rendered lighting.
