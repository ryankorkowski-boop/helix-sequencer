APPROVED CONCEPTS 1–62 — NATIVE XLIGHTS SHOWS

Each numbered folder is an independent xLights show. Set it as your show folder,
open the matching *_Showcase.xsq, Render All, then play. Use xLights 2026.18 or newer.

Includes XML layout/network files, reusable models/*.xmodel, submodels/groups,
XSQ sequences, native FSEQ data, channel inventory, manifests and required local assets.
Movies are provided separately in the release and MP4 ZIP. Source concept art remains
in the repository's showcase/concepts directories.

All 62 sequences are 24-second silent Animation studies. Designs 43–62 demonstrate
held replacement poses, successive assembly, or domino state changes on static props.
No controllers are configured. Geometry is an artwork-guided planning interpretation.
Lenticular occlusion, fabrication, real rigging and music transcription are not part
of this export.

Original 1–22 XML/XSQ files match the prior checked-in exports byte for byte.
See VERIFICATION.json for source hashes, native render and MP4 validation.
