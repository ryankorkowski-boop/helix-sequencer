Helix Sequencer — Beta 1.3
One-part portable folder. Unzip the whole archive and keep this folder together.

Run Helix.exe. HelixCLI.exe is the console worker the window uses; do not delete it or the _internal folder.

This build writes section colors into the sequence palette table. White is an accent on strobe, twinkle, shimmer, snowflake, and sparkle.

Version: Beta 1.3 (1.3.0-beta)
