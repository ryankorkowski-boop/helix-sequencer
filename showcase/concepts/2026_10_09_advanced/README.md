# Helix advanced perspective concepts — 23–42

Twenty new visual concepts on ten paired plates. Concept artwork only; all await explicit user approval before any xmodels, layout XML, sequences or native previews are created.

The prior native builds favored readable silhouettes, separate layers, exact finite geometry and clear negative space. This round explores alignment from a viewing zone, scaled receding structures, apparent impossible topology and volumetric light meshes. The artwork expresses intended visual effects; it does not prove optical alignment or native/physical feasibility.

## Approval and implementation boundary

Reply with concept IDs to approve, reject or revise. No selection is inferred from opening a file. Any future native build needs the chosen hero viewpoint and audience zone first. Frame sizes/depth offsets, occlusion/baffles, supports and wiring must be designed then. Lens/camera, physical viewing position and overlap materially affect these illusions.

The new whale (27) is original artwork, not a recovered copy of the earlier missing whale. Stage drummer figures indicate proposed riser placement, not new approved drummer geometry or musical acceptance.

All original concept art, native layouts, original media and canonical drummer assets remain unchanged. No XML/XMODEL/XSQ/FSEQ/MP4 belongs to this concept-only round. See MASTER_TODO.md for continuity.
