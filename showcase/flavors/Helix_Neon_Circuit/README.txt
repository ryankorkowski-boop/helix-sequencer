HELIX NEON CIRCUIT — ULTIMATE SHOWCASE

104 models / 27 stock families / 36 spiral trees / 13 double helices

1. Extract this entire folder; keep assets/ and models/ alongside the XML.
2. In xLights, select this folder as a NEW show directory. Use xLights 2026.18 or newer.
3. Open Layout in 3D. Use Default preview and Restore Default ViewPoint or load Neon Circuit overview.
4. Open Helix_Neon_Circuit_Showcase.xsq for the 24-second lighting demonstration (no audio required).
5. Open Helix_Neon_Circuit_3D.html in a browser for the portable orbit/zoom design review.

This is a standalone layout. Existing Helixia/user layouts and drummer assets are unchanged.
DNA models expose STRAND_A, STRAND_B, RUNGS, RUNGS_EVEN, RUNGS_ODD and TOP submodels.
Spiral tree strands, spinner rays, zones and native families also have sequencing groups.
DMX, servo, AC, Image and Label models are isolated control fixtures; the demo sequences only RGB pixels.
No physical controllers are configured. Models use absolute Start Channel; add controllers/ports for an actual installation.
Dimensions are design feet, not an engineering/fabrication plan.
Sparse custom geometry is identical in XML and review. Native stock shapes have illustrative review coordinates; consult native verification evidence.
